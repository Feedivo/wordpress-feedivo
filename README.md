# Feedivo for WordPress

Show your Instagram, Facebook, Threads, Pinterest and YouTube posts on a
WordPress site as local content: images land in the media library, feeds are
placed with the block **Feedivo Feed**, the Elementor widget or the shortcode
`[feedivo feed="…"]`. Feeds are built and designed in your
[Feedivo](https://feedivo.de) account; WordPress keeps a local copy and
refreshes it every five minutes.

- Install from the [WordPress plugin directory](https://wordpress.org/plugins/feedivo/)
  (search for "Feedivo" under *Plugins → Add New*)
- Product page and setup guide: [feedivo.de/wordpress](https://feedivo.de/wordpress),
  [help article](https://feedivo.de/hilfe/benutzerhandbuch/wordpress-plugin)
- Support: [wordpress.org/support/plugin/feedivo](https://wordpress.org/support/plugin/feedivo/)

This repository mirrors the released plugin exactly as published in the
WordPress plugin directory; each release is a tag. Details for users, the
changelog and the external-service disclosure are in `readme.txt`.

Requires WordPress 6.3 or newer and PHP 7.4 or newer. License: GPL-2.0-or-later.
